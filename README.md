# Brady Shaw | Portfolio Website

Personal portfolio and resume site for Brady Shaw, a statistics student at 
Utah State University (B.S. expected December 2026) interested in data science 
and business applications.

**Live site:** https://bradyashaw.github.io

## What's on the site

- **Home:** a short introduction and links to GitHub, LinkedIn, and email
- **Projects:** write-ups of my data science and statistics work, including the 
question, method, results, and my role
- **Resume:** a downloadable PDF of my current resume
- **About:** more about how I work and what I'm looking for

## Built with

- [Quarto](https://quarto.org/) for the site
- R and RStudio for the project analyses
- GitHub Pages for hosting

## Repository structure

- `_quarto.yml`: site settings and navigation
- `index.qmd`, `about.qmd`, `resume.qmd`: main pages
- `projects.qmd` and `projects/`: project listing and individual project pages
- `styles.css`: custom styling
